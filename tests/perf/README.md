# اختبارات الأداء — `tests/perf`

بتشغّل الموقع في سيناريوهات حقيقية (تحميل، سكرول لكل قسم، سحب الحلقة، الماوس على الكروت، فتح المشروع، تغيير اللغة) وبتطلع **أرقام لكل مكان** وتقارنها بميزانيات ثابتة في `budgets.json`. مفيش أي مكتبات محتاجة تتسطب: Node 22+ وأي Chrome/Edge موجود على الجهاز.

## التشغيل

```bash
node tests/perf/run.mjs                      # ديسكتوب 1366×768
node tests/perf/run.mjs --profile mobile     # موبايل 390×844، لمس، المعالج أبطأ 4 مرات
node tests/perf/run.mjs --headed             # نافذة ظاهرة = كارت الشاشة الحقيقي (أرقام الـ FPS الصح)
node tests/perf/run.mjs --net slow4g         # نت بطيء لأرقام التحميل
node tests/perf/run.mjs --only modal,lang_toggle
node tests/perf/run.mjs --baseline           # احفظ الأرقام دي كنقطة مقارنة
```

أو من المتصفح: شغّل السيرفر وافتح `http://127.0.0.1:5173/tests/perf/` واضغط **Run** (خلي التاب ظاهر وهو شغال).

كل تشغيل بيكتب `reports/<profile>-latest.json`، ولو في `reports/<profile>-baseline.json` بيطبع جدول **Δ vs BASELINE** بالفرق في كل رقم. الأمر بيرجّع exit code ‏1 لو ميزانية اتكسرت، فينفع يتحط في CI.

## الأرقام معناها إيه

| العمود | المعنى | الميزانية |
|---|---|---|
| `fps` / `smooth` | نسبة الفريمات اللي اترسمت فعلًا من اللي الشاشة طلبتها (1 = مفيش ولا فريم وقع) | ≥ 0.9 |
| `p95` / `max` | زمن الفريم بالملّي ثانية؛ 16.7 = ‏60Hz | p95 ≤ ضعف فريم الشاشة |
| `>50` | فريمات أطول من 50ms (تقطيع واضح) | ≤ 2 |
| `block` | وقت حجز الـ main thread من Long Animation Frames | ≤ 50ms |
| `CLS` | تحرّك المحتوى من مكانه | ≤ 0.01 |
| `layouts` / `styles` | عدد مرات حساب الـ layout والـ style (من DevTools، في الـ CLI بس) | — |
| `busy%` | نسبة انشغال الـ main thread طول السيناريو | ≤ 60% |

سيناريوهات فيها أرقام إضافية: `spotlight_*` (زمن معالج الماوس في كل فريم)، `modal` (زمن فتح النافذة)، `lang_toggle` (زمن تبديل اللغة). وفي آخر التقرير جدول **IMAGES** بيقارن حجم كل صورة الحقيقي بالحجم اللي بتظهر بيه.

**ملاحظة:** في الوضع العادي (headless) Chrome بيرسم على المعالج مش كارت الشاشة، فالأقسام التقيلة في الرسم (حلقة المشاريع) بتبان أبطأ من الحقيقة. عشان كده مشاكل الـ FPS في الوضع ده بتطلع **تحذير** مش فشل؛ اتأكد منها بـ `--headed`.

## الملفات

- `harness.js` — السيناريوهات والقياس والميزانيات (بيشتغل في المتصفح)
- `index.html` — واجهة التشغيل من المتصفح
- `run.mjs` — التشغيل من الترمنال عن طريق DevTools Protocol + عدادات المحرك
- `early.js` — بيتحقن أول ما الصفحة تبدأ عشان يلقط أرقام التحميل من البداية
- `budgets.json` — الحدود المسموحة؛ `null` بيقفل الاختبار لسيناريو معيّن
